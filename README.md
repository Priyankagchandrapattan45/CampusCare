# CampusCare 🏫

**CampusCare** is a full-stack campus issue management system that helps students report campus-related problems and allows administrators to manage and track those issues efficiently.

## 📌 About the Project

Students may face different problems on campus, such as maintenance issues, cleanliness problems, infrastructure problems, or facility-related concerns.

CampusCare provides a centralized platform where students can report these issues and administrators can view, manage, and update their status.

## ✨ Features

* Student registration and login
* Report campus issues
* Add issue location
* Select issue category
* Set issue priority
* Track issue status
* Admin issue management
* User management
* Database storage

## 🚀 How to Run

### 1. Start the Backend

Open a terminal in the project folder and run:

```bash
cd backend
python app.py
```

The backend runs on:

```text
http://127.0.0.1:5000
```

### 2. Start the Frontend

Open another terminal and run:

```bash
cd frontend
npm install
npm run dev
```

The frontend normally runs on:

```text
http://localhost:5173
```
